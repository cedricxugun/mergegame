# 林间营地六边形合成原型

面向 iPhone 竖屏的单区域试玩。模拟八次三消胜利，手动打开素材箱，通过二合、占地扩张、地块开放、修桥和离区结算完成营地。

初始为七格工作区。建设拆成十个阶段：小树、树丛、林荫小径、水源、溪湾、第一顶帐篷、双营位、篝火、木桥、大营地。已建景物原位升级，每增加一格景观占地就补开一格工作地；工作容量依关键阶段从 7 增至 13、19、23 格。最终十四格景观与二十三格工作区合计三十七格。多格素材使用去除内部共享边的完整外轮廓，米色工作地格、凸起素材底座和绿色石边景观区分别呈现。

高阶素材可连续完成同链的多个建设阶段，超额部分按同链等价素材退回背包。八箱物资仍足够完成全部建设，标准路线最后结算三点旅行补给。旧版进度会迁移，已有素材与已建景物保留。

近景保留较大的操作格，拖动空地可平移视角；全景查看整个营地，世界地图展示周围四个不同主题的地区。其他地区仅供预览，本次可建设区域为林间营地。

运行：`npm run dev`，打开终端输出的本地地址。无外部依赖和构建步骤。

检查：`npm test`。浏览器测试可打开 `/?qa=construction`，使用独立的会话存档，不影响正常试玩进度。Windows 安装 Chrome 时，也可在本地服务运行期间执行 `node scripts/browser-check.mjs`，把截图保存在忽略的 `.preview` 目录。

游戏资源位于 `dist`。存档只保存在当前浏览器；设置中可以重新开始。支持拖拽或依次点选同类同级素材合成、旋转三格景物、免费暂存、撤销、合成提示、阶段建设、修桥及剩余素材结算。执行 `npm run build:offline` 可生成 `offline/forest-camp.html` 单文件版本。
