# 林间营地六边形合成原型

面向 iPhone 竖屏的单区域试玩。模拟八次三消胜利，手动打开素材箱，通过二合、占地扩张、地块开放、修桥和离区结算完成营地。

初始开放七格；树林首次达到 L4 后开放到十九格，溪湾落成后开放到三十一格，木桥修复后开放到三十七格。近景保留较大的操作格，拖动空地可平移视角；全景查看整个营地，世界地图展示周围四个不同主题的地区。其他地区仅供预览，本次可建设区域为林间营地。

运行：`npm run dev`，打开终端输出的本地地址。无外部依赖和构建步骤。

检查：`npm test`。Windows 安装 Chrome 时，可在本地服务运行期间执行 `node scripts/browser-check.mjs`，验证真实指针操作、完整建设、结算和存档，并把截图保存在忽略的 `.preview` 目录。

游戏资源位于 `dist`。存档只保存在当前浏览器；设置中可以重新开始。支持拖拽或依次点选同类同级素材合成、旋转三格景物、免费暂存、撤销、合成提示、主动落成、修桥及剩余素材结算。
