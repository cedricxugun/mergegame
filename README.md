# 林间营地六边形合成原型

面向 iPhone 竖屏的两站六边形造景试玩。第一站林间营地只需一次三消胜利；第二站芦苇河湾需要三次胜利、三箱物资和六个建设阶段。两站使用相邻的同一套六边形坐标，泉眼、溪流和岸边小路会随着建设连通。

从默认入口完成林间营地后，可结算余料并进入河湾，也可通过顶部地区标签往返。`/?start=river` 是第二站独立试玩入口：附带明确标识的已建好示例营地和 1 点补给，使用单独存档，不改变默认入口的真实旅程进度。

芦苇河湾的三条链为水滴→浅水洼→清泉→连通溪流、芦芽→青芦→芦苇簇→芦苇岸、木条→木板→栈桥段→小渡口。每箱提供本链 L2 ×4、L1 ×1，普通路线合成两份 L3，分别交付以完成 1 格初建和 3 格原地扩建。手动提前合成 L4 也能一次完成同链两阶段；扩建预览显示实际消耗、最终占地与阶段数。

第二站工作格从 9 增至 11、13，建设不会吃掉工作格。第一段泉眼恢复营地东侧的水流，第二阶段把溪水引进河湾；芦苇岸长成后出现白鹭，栈桥阶段把营地小路接到河边，最终渡口有停靠的小木船和沿岸走来的旅人。「连片全景」使用两站的真实位置与同一条连续水路，可点地图标签回看两站。两站完成后的地形合计 41 格，工作区、固定地景与连接地块互不重叠。

第二站余料为水滴、芦芽、木条各一份，结算 +3 点；连同第一站带来的 1 点，旅途补给合计 4 点。玩家可以提前完成三次模拟胜利、开完全部箱子，溢出素材进入暂放区；同级素材仍可从暂放区参与合成和建造。

默认入口为 `dist/index.html`（与 `first-stop.html` 相同），使用 `first-stop.mjs`、`first-stop-app.mjs` 和 `first-stop.css`。第一箱提供小树 ×2、帐篷组件 ×2、树种 ×1。小树合为三格树丛，组件合为一格帐篷；两个蓝图依次在地图上直接显示需求和可交付状态。拖到蓝图或点击任务卡进入预览，确认后播放素材移动动画。树丛落成开放两个相邻工作格，原有七格全部保留。

两处景观完成后，树林、营位、道路和原工作空地绘制为同一片连续草地，移除内部格线，出现灌木、路灯、路标与沿路行走的旅人。剩余一颗树种结算为一点旅行补给，可以带入已开放的芦苇河湾；山坡等其他地区目前只提供风景预览。支持拖拽或点选合成、整件自动让位、旋转、暂放区、撤销、音效和本地存档。减少动态效果偏好下停止装饰动画。

两站旅程沿用存档键 `forest-camp.first-stop.v1`：保留旧的第一站 `state/history`，新增 `river/riverHistory/active`，兼容第一站未完成、已完成或此前选择山坡的存档。两站分别撤销，返回营地不会重置河湾；重置河湾会保留第一站。独立试玩键为 `forest-camp.first-stop.v1.river-demo`。上版八局营地的文件和 `forest-camp.hex.v1` 存档均保留，可从设置中的“回看上版营地”访问 `extended.html`。

下文为上版完整营地的规则说明。

初始为七格工作区。建设拆成十个阶段：小树、树丛、林荫小径、水源、溪湾、第一顶帐篷、双营位、篝火、木桥、大营地。已建景物原位升级，每增加一格景观占地就补开一格工作地；工作容量依关键阶段从 7 增至 13、19、23 格。最终十四格景观与二十三格工作区合计三十七格。多格素材使用去除内部共享边的完整外轮廓，米色工作地格、凸起素材底座和绿色石边景观区分别呈现。

高阶素材可连续完成同链的多个建设阶段，超额部分按同链等价素材退回暂放区。八箱物资仍足够完成全部建设，标准路线最后结算三点旅行补给。旧版进度会迁移，已有素材与已建景物保留。

底部主按钮随当前目标提示下一步：领取物资、开箱、合成、预览建造或结算。建造保留固定规划位置，先显示蓝图、真实交付素材和完成阶段数，确认后播放素材移向蓝图的动画；取消预览不会消耗素材。已完成景物留在地图并原位升级。暂放区只在有素材时显示，素材可取回，也能直接参与合成和交付。

拖放到已占用的工作地格时，相同种类同等级优先合成，其他素材会寻找空地整体让位。拖动中显示目标轮廓与让位落点，放手后执行同一布局并播放移动动画。源素材腾出的格子也可使用；三格素材可整体旋转安置。若没有合法布局，整个移动取消，不会将挡位素材悄悄收入暂放区。固定景观不能被挤走。

近景保留较大的操作格，拖动空地可平移视角；全景查看整个营地，世界地图展示周围四个不同主题的地区。其他地区仅供预览，本次可建设区域为林间营地。

运行：`npm run dev`，打开终端输出的本地地址。无外部依赖和构建步骤。

检查：`npm test`，包含两站与上版营地共 36 项规则测试。浏览器测试打开 `/?qa=river-v6`，使用独立会话存档，不影响正常试玩进度。以 390 × 844 手机视口验证手动合成、原地扩建、泉水接通、跨区往返、连片全景和两站补给结算；同时检查较窄手机屏幕和减少动画偏好。截图保存在忽略的 `.preview` 目录。

游戏资源位于 `dist`。存档只保存在当前浏览器；设置中可以重新开始。执行 `npm run build:offline` 生成新版 `offline/forest-camp.html` 和上版对照 `offline/forest-camp-extended.html`，两个文件均包含全部脚本和素材。
