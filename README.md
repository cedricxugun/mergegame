# 风暴之后 · 归乡手记

当前默认入口是灾后重建版，仍面向 iPhone 竖屏。米拉带着莉娜回到风暴后的故乡：先补好避雨棚，再生火、清出旧路、完善营地；随后进入芦苇河湾恢复水源、护岸和渡口，接回船匠罗恩。剧情随着修复进入手记，未完成的成品不会提前显示。

核心规则在 `dist/homecoming-play.mjs`（世界存档 v8）；`homecoming.mjs` 冻结保留 v7 行为，供旧存档校验与兼容。`homecoming-view.mjs`、`homecoming-app.mjs` 和 `homecoming-craft.css` 负责展示。`index.html` 与 `homecoming.html` 使用相同入口。三消通关获得物资箱，再回地图选材、一键领料、亲手合成并修复。营地仍对应第 1–8 关和 4 次修复，河湾对应第 9–20 关和 6 次修复；L1–L6 占单格，L7 展开三格。

本版增加建设分支：棚顶之后炉架与旧路可择先；泉眼之后水渠与护岸可择先；草垫完成后开放绿带与栈桥。选中的目标持续保留，地形、景观与剧情按实际任务 ID 更新。物资箱可在已开放目标的材料链中选择，按唯一箱号核算；少量高等级产物拆成两个低一级素材，总价值不变。边缘地块可通过相邻合成或搬入达标组件清理，组件保留，新增地格可继续合成；区域完成后也能清理遗漏地块。玩法判断与下一轮试玩问题见 [GAMEPLAY-REVIEW.md](GAMEPLAY-REVIEW.md)。这是一版轻策略验证，不代表趣味性已获玩家验证。

河湾的“下一件组件”由 `homecoming-momentum.mjs` 根据当前材料计算：不必一直盯着最终 L7，先追 L5 蓄水组件、再追 L6 水渠模块，最后合成三格溪流组件。两份前一级组件各自显示原料进度；下一箱预览说明加上库存后能合到哪里。只有实际剩余物资足够时才说“再赢 1 局”，已赚到的箱子和箱内材料都会计入，不提前承诺修复。中间组件合成后有短促的高亮和下一步反馈。材料总量、配方、三消关数和存档版本保持不变。

三消规则在 `match3-premium.mjs`，界面在 `match3-premium-ui.mjs` / `match3-premium.css`，奖励由 `journey-match.mjs` 桥接。棋盘 7 列 × 8 行，有 20 份独立的木箱、加固木箱、泥地与缺口布局。木箱阻挡交换和落子，在旁边消除或直接命中可以拆除；拆除后该格加入落子区域。第一关预置一个螺旋桨，并保证提示的四连合出火箭、落在螺旋桨旁边，让玩家实际尝试运送火箭清理木箱。其余棋子按种子随机补充，不预设胜利结果。

四个成排生成火箭，2×2 方块生成螺旋桨，T/L 形生成炸弹，五个成排生成彩球。炸弹清理 5×5，双炸弹清理 9×9（按边缘裁切），火箭炸弹清理三行三列。双螺旋桨飞向三个不同目标；螺旋桨可以把火箭或炸弹送到目标；彩球搭配道具会把数量最多的普通颜色转为对应道具并引爆；双彩球清盘并去掉障碍的一层。道具可以点击，组合需要滑动交换。无效交换不扣步，无可用操作免费重排。小锤、横扫、竖扫和洗牌每局各免费一次。

棋子采用原创有体积的 PNG，配蓝金目标栏与林间背景。当前动画不再每帧替换整盘 DOM：保留棋子节点，滑动超过约四分之一格即开始交换，无需等到松手。规则帧记录道具触发来源，`match3-motion.mjs` 计算命中时刻，`match3-effects.mjs` 播放蓄力、组合汇聚、火箭沿线命中、螺旋桨飞行与携带、彩球转换、碎片和目标收集。重力下落随距离变化，后续连消略加速。

连消期间，互不影响的列可以同时交换：新操作必须指向仍在原位的同一棋子，且它的全部后续消除、下落和重排都不能碰到正在动画的列。否则暂存最多两次操作，稳定后再次核对棋子身份。每个接受的操作先保存完整规则结果，动画只影响显示，刷新不会丢失步数或重复奖励。本版尚未实现商业游戏的逐格流体并发与完整关卡生态；仍需真机帧率和大规模关卡调优。

合成端使用 11 张新增原创 PNG：4 张材料图集覆盖全部 28 级素材，2 张场景图集覆盖两站修复阶段，1 张遗址图集、莉娜和罗恩肖像、林地背景及物资箱。SVG 仅承担图集裁框、可操作六边形和动画几何；实物不再使用旧占位图。图集通过 SVG pattern 绘制，保证实际点击与飞行动画边界只覆盖单个素材。统一等距视角、左上光照、暖木、绳索和蓝绿色细节。高等级画待安装构件，建成景观只在交付后揭晓。内置 image_gen 的完整提示词与检查结果见 `ASSET-PROMPTS-v11.json`。

故事从“留一盏等大家回家的灯”开始，贯穿避雨、热饭、旧路、水源、护岸和通航。开场、10 次修复、抵达河湾和结尾共 13 段对话；支持跳过、手记回看和对话断点保存。修复后先出现材料飞入、施工光点、景观与新空地，再进入角色对话。旧存档不补播过去的对话，后续阶段正常触发；奖励与材料配方保持原进度。

每关有独立目标和有限步数；全部目标完成才显示通关领取。步数耗尽且目标未完成不发箱，可以免费重试新开局。返回地图或刷新会保留棋盘、剩余步数和道具；尚未领取的胜利也会保留。奖励同时校验关卡、所属区域、领取前的胜利次数及完整通关状态，领奖后立即清除该对局并保存。重复点击不能重复发箱。已赢得的关卡成为撤销边界，地图内仍能撤销开箱、合成与修复。旧版建设进度可以继续使用，后续新增箱子需通过三消获得。

地图使用“领取素材 → 合成升级 → 送去修复”三步提示，任务卡显示真正需要交付的材料图。通关奖励箱会从三消结算页飞回地图；物资箱默认一键开启并成批领取，材料优先落到当前区域中间的空地；放不下的留在箱中。每次只开启一箱、只放到一个区域；当前区域满了后，下次领取才会定位到另一侧空地。箱子下方可选单件领取或先开箱留着。默认暂存 6 件，旧存档超量暂存保留容量。两件素材会飞向同一落点，再出现新等级。支持直接拖拽与依次点选两件素材合成。主按钮只提示搭档，不代替玩家合成；选中素材时优先寻找它的同级搭档。地图与暂放区的可交付材料都有绿色勾。修复完成后保留成果卡和新增空地反馈，点击继续后才出现下一个现场任务。

四条链共有 28 个独立材料图 `mat-{chain}-{level}.svg`，从基础材料逐步长成未安装构件，成品景观只在修复后出现。成长图鉴会记住已经消耗的高阶素材，保存于同一存档的可选 `discoveries` 字段；旧存档可直接续玩。地区标签显示地图素材数量，跨区选中后可以一键定位；合成与取回素材会同时同步地区标题和视角。窄屏施工预览会把整个落点移入可见范围，拖动地图有边界限制。全景淡化格线，恢复水流后营地沿岸出现花草，篝火有暖光。减少动画偏好下禁用飞行动画、引导移动与飘雨。下一步建议按状态缓存，避免在每一件素材绘制时重复搜索布局。

两站共用一份世界坐标、物品清单与合法地格。所有带浅格线的草地和道路均可摆放；干渠、水面、遗址和建筑只阻挡明确显示的占地。已建营地的 24 格可用空地进入河湾后保持开放。基础两站合计 67 格地形、49 格可用空地；4 个可选边缘地块全部清理后增至 71 格地形、53 格可用空地。每次扩建会预先检查并移动完整的挡位素材，同时清出相邻新地；放不下时整个操作取消。前期没有成品蓝图，只有遗址与当前任务；确认前仅显示落点、新空地和让位落点，确认后素材飞到现场并揭晓修复效果。

营地余料为木片 1 份；河湾额外余料为水滴、芦芽、木条各 1 份。结算会包括箱中尚未领取的素材，可选择保留或按等级价值转换为补给，正常路线两站总余料价值 4。选择保留后素材仍然可移动、合成和暂放；地图不会因为完成而关闭。点击素材后切换地区，再点空地，可以跨区移动；拖动地图空白处平移视角，定位按钮恢复视角。

本版继续使用 `forest-camp.homecoming.v1` 存档键；v7 世界自动升级为 v8，保留库存、摆放、胜利次数、三消对局及符合检查点的撤销记录。更早的 first-stop/hex 存档不变。可选 `matchSession` / `matchOpen` 字段保存三消对局，`discoveries` 保存素材图鉴。旧三消 `version:1` 已操作的对局仍由保留的 `match3.mjs` 完成；尚未操作的旧对局自动升级为新布局，原有建设进度保持。新对局使用 `version:2`。`/?start=river` 提供独立河湾试玩，附带已建示例营地，从三消第 9 关开始；`/?qa=<name>` 使用独立会话进度与可复现种子。设置里的“回看上一版”保留旧版模拟胜利原型。当前三消包含 11 张 `premium-*.png` 和 1 张 `match-garden-bg.png`；棋子以颜色和轮廓同时区分。

运行 `npm run dev` 后打开 `http://127.0.0.1:4178/`。`npm test` 覆盖两版三消的无效交换、步数与连消、道具生成和组合、木箱、泥地、免费重排、失败与最后一步胜利、存档恢复、单次领奖，以及通过 20 个三消关卡后完成两站重建的完整价值守恒。原有合成、地格、引导和素材测试继续保留。`npm run build:offline` 生成新版 `offline/forest-camp.html`，以及旧版对照；脚本、样式、PNG 和 SVG 均内嵌，三消无需联网。浏览器验收采用 390×844 与 320×740 视口，真实点击、滑动、领奖、开箱、合成和修复，不写入虚构胜利状态。

## 上版原型说明（保留用于对照）

面向 iPhone 竖屏的两站六边形造景试玩。第一站林间营地只需一次三消胜利；第二站芦苇河湾需要三次胜利、三箱物资和六个建设阶段。两站使用相邻的同一套六边形坐标，泉眼、溪流和岸边小路会随着建设连通。

从默认入口完成林间营地后，可结算余料并进入河湾，也可通过顶部地区标签往返。`/?start=river` 是第二站独立试玩入口：附带明确标识的已建好示例营地和 1 点补给，使用单独存档，不改变默认入口的真实旅程进度。

芦苇河湾的三条链为水滴→浅水洼→清泉→连通溪流、芦芽→青芦→芦苇簇→芦苇岸、木条→木板→栈桥段→小渡口。每箱提供本链 L2 ×4、L1 ×1，普通路线合成两份 L3，分别交付以完成 1 格初建和 3 格原地扩建。手动提前合成 L4 也能一次完成同链两阶段；扩建预览显示实际消耗、最终占地与阶段数。

第二站工作格从 9 增至 11、13，建设不会吃掉工作格。第一段泉眼恢复营地东侧的水流，第二阶段把溪水引进河湾；芦苇岸长成后出现白鹭，栈桥阶段把营地小路接到河边，最终渡口有停靠的小木船和沿岸走来的旅人。「连片全景」使用两站的真实位置与同一条连续水路，可点地图标签回看两站。两站完成后的地形合计 41 格，工作区、固定地景与连接地块互不重叠。

第二站余料为水滴、芦芽、木条各一份，结算 +3 点；连同第一站带来的 1 点，旅途补给合计 4 点。玩家可以提前完成三次模拟胜利、开完全部箱子，溢出素材进入暂放区；同级素材仍可从暂放区参与合成和建造。

默认入口为 `dist/index.html`（与 `first-stop.html` 相同），使用 `first-stop.mjs`、`first-stop-app.mjs` 和 `first-stop.css`。第一箱提供小树 ×2、帐篷组件 ×2、树种 ×1。小树合为三格树丛，组件合为一格帐篷；两个蓝图依次在地图上直接显示需求和可交付状态。拖到蓝图或点击任务卡进入预览，确认后播放素材移动动画。树丛落成开放两个相邻工作格，原有七格全部保留。

两处景观完成后，树林、营位、道路和原工作空地绘制为同一片连续草地，移除内部格线，出现灌木、路灯、路标与沿路行走的旅人。剩余一颗树种结算为一点旅行补给，可以带入已开放的芦苇河湾；山坡等其他地区目前只提供风景预览。支持拖拽或点选合成、整件自动让位、旋转、暂放区、撤销、音效和本地存档。减少动态效果偏好下停止装饰动画。

两站旅程沿用存档键 `forest-camp.first-stop.v1`：保留旧的第一站 `state/history`，新增 `river/riverHistory/active`，兼容第一站未完成、已完成或此前选择山坡的存档。两站分别撤销，返回营地不会重置河湾；重置河湾会保留第一站。独立试玩键为 `forest-camp.first-stop.v1.river-demo`。上版八局营地的文件和 `forest-camp.hex.v1` 存档均保留，可从设置中的“回看上版营地”访问 `extended.html`。

下文为上版完整营地的规则说明。

初始为七格工作区。建设拆成十个阶段：小树、树丛、林荫小径、水源、溪湾、第一顶帐篷、双营位、篝火、木桥、大营地。已建景物原位升级，每增加一格景观占地就补开一格工作地；工作容量依关键阶段从 7 增至 13、19、23 格。最终十四格景观与二十三格工作区合计三十七格。多格素材使用去除内部共享边的完整外轮廓，米色工作地格、凸起素材底座和绿色石边景观区分别呈现。

高阶素材可连续完成同链的多个建设阶段，超额部分按同链等价素材退回暂放区。八箱物资仍足够完成全部建设，标准路线最后结算三点旅行补给。旧版进度会迁移，已有素材与已建景物保留。

底部主按钮随当前目标提示下一步：领取物资、开箱、合成、预览建造或结算。建造保留固定规划位置，先显示蓝图、真实交付素材和完成阶段数，确认后播放素材移向蓝图的动画；取消预览不会消耗素材。已完成景物留在地图并原位升级。暂放区只在有素材时显示，素材可取回，也能直接参与合成和交付。

拖放到已占用的工作地格时，相同种类同等级优先合成，其他素材会寻找空地整体让位。拖动中显示目标轮廓与让位落点，放手后执行同一布局并播放移动动画。源素材腾出的格子也可使用；三格素材可整体旋转安置。若没有合法布局，整个移动取消，不会将挡位素材悄悄收入暂放区。固定景观不能被挤走。

近景保留较大的操作格，拖动空地可平移视角；全景查看整个营地，世界地图展示周围四个不同主题的地区。其他地区仅供预览，本次可建设区域为林间营地。

运行：`npm run dev`，打开终端输出的本地地址。无外部依赖和构建步骤。

检查：`npm test`，包含两站与上版营地共 36 项规则测试。浏览器测试打开 `/?qa=river-v6`，使用独立会话存档，不影响正常试玩进度。以 390 × 844 手机视口验证手动合成、原地扩建、泉水接通、跨区往返、连片全景和两站补给结算；同时检查较窄手机屏幕和减少动画偏好。截图保存在忽略的 `.preview` 目录。

游戏资源位于 `dist`。存档只保存在当前浏览器；设置中可以重新开始。执行 `npm run build:offline` 生成新版 `offline/forest-camp.html` 和上版对照 `offline/forest-camp-extended.html`，两个文件均包含全部脚本和素材。
